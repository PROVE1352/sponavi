## Problem Statement

2026 KSPO 공공데이터 활용 경진대회(서비스 개발 부문, 마감 2026-10-02)에서 수상하는 것. 심사는 **발표 없이 보고서 10장 + 서비스 URL**뿐이다(공고문 HWPX 실물, E87). 배점: 독창성 25 · 실용성 20(시장 규모) · 적절성 20 · 발전가능성 20(매출 가능성) · 기술성 15. 사회가치 축 없음. 특별상 2팀 = 종합 10위 내 발전가능성 상위 2.

현재 위치(7/21 격리 모의심사): 57.5~61.5 / 잠재 77~78.5. 최약축 = 발전가능성 3~4점(매출 서사 공백). 3심이 명령한 사람 게이트 3개(7/27 인터뷰·복지 검수자·중개자 채널)는 **전부 미실시** — 로컬 맥·서버·Nodian 전수 확인, 결과물 없음. 목격자 0명인 상태로 5주 안에 서류와 URL만으로 이겨야 한다.

## What Makes This Cool

사용자의 말: **"회색지대 사람들이 도움을 받을수있고 C까지"**. 와 순간은 기능이 아니라 한 사람의 여정이다 — 27세, 소득 '그 외', 성북구. 이용권 ✗. **그 다음 문장**이 스포내비다: 지금 바로 되는 것 3가지 → 내 체력 공식 판정 → 왜 이 운동 → 실제 근처 강좌.

심사위원은 혼자 URL을 연다. 그래서 이 여정은 **설명 없이 스스로 재생**돼야 한다: `/#/demo?p=P2&auto=1` 한 링크가 30초 안에 끝까지 흐르고, 보고서 1쪽 QR이 그 링크다. 같은 서비스의 뒷면 `gap.html`은 공급공백 엔진을 정책담당자가 정렬해 보는 "가맹 유치 우선순위" 정적 표 1장으로 만든다 — 발전가능성을 문장이 아니라 물건으로. 시민용 앞면 + 정책용 뒷면 = 양면 제품.

와이어프레임: `docs/designs/sketch-p2-journey.png` (HTML 동봉, 리뷰 반영판: ①은 페르소나 칩 에코·LLM 0회, ② 공공시설 배지는 "큐레이션 · 검증 대기", ③ 값은 25~29세 기준표 기준). **스케치의 시설 수·건수는 자리표시이지 실측값이 아니다** — 보고서에는 DB 실측만 쓴다. 위계: ✗ 카드는 작게 남기고(FR-02 AC4) "지금 바로 되는 것"이 히어로.

## Constraints

- **판결 제약(SPEC §0, 3심)**: P-1 정직성 · P-2 레인 분리(자격·위치·가격 결정론, AI는 체력처방 문장만) · P-3 비저장 · 공급공백 정직 신호 · "AI 추론"이라 부르지 않기 · 공급공백은 장벽2의 증거로 종속 배치(고발 아닌 안내 — 판사3).
- **범위 개정 선언**: PRD §8·SPEC §1의 "B2G 대시보드 제외"는 유지하되, **정적 표 1장(`gap.html`)만 예외**로 둔다. gap.html에 한해 React 라우트·API·e2e를 늘리지 않는다(자동재생의 e2e 1건·서버 리다이렉트 2줄은 앞면 작업이라 별개). W1 문서 작업으로 CUTLINE 행 1개 + PRD §8에 예외 1줄 추가.
- **일정**: 9/5 챗 UI 시각 확정(스샷 종속) · 9월 학기 시작(7과목) · 10/2 접수 마감(수정 제출 가능) · **9/17 코드·데이터 동결** — 이후 코드 수정은 거짓 출력(P-1) 봉합만 허용, **DB 재빌드·`refresh_data.sh` 금지**. `deploy.sh`는 `rsync -az --delete ./`라 `data/sponavi.db`도 실어 나른다 → 동결 시 `shasum data/sponavi.db` 기록, 봉합 배포 전 해시 일치 확인(또는 `--exclude data/sponavi.db`)(재빌드 시 geocoded 619건 소실 → 데모 구 거리 전부 "미표기" 회귀 + 보고서 수치 이탈, EDGE G-04), 인프라 복구·인증서 갱신은 예외. 9/5가 밀리면 히어로 에이전트를 W2에 병렬로 붙이고 스샷은 9/10 확정, 9/17은 하드스톱.
- **팀**: 2인(CS 2학년 + 체대). 코딩은 Claude Code 병렬 에이전트(Opus, effort high). 속도 실증: 8월 3일간 42커밋.
- **배포**: Oracle A1, docker 단일 컨테이너 :8100. Caddy는 이미 nodian.kro.kr을 443으로 서빙 중 → 80/443 인그레스·iptables는 실증됨. sponavi.kro.kr A레코드 등록(사용자 1분, 서버 공인 IP는 deploy.sh 참조) 후 `deploy/deploy.sh`가 Caddyfile append. 현재 HTTP만.
- **금지**: 인터뷰·시장 수치 날조. 없으면 없다고 쓴다. **서비스 DB에** 새 데이터소스 추가 금지(KOSIS 등록장애인 컬럼 삭제) — 보고서의 시장 수치 1개는 공식 통계 인용이라 해당 없음.
- **시설 출처 라벨(P-1, 3차 리뷰 발견)**: data.go.kr 15113986 raw `faci_gb_nm` = 신고 107,407 / 공공 44,747 / 등록 634인데 `build_db`가 전부 `source='public'`으로 합치고 앱이 "공공체육시설"로 라벨한다(성북구 647 = 공공 57 + 신고 590). 공단 심사위원은 자기 데이터라 즉시 안다. 앱 `AltRow` 배지는 공공/신고·등록 구분(W1), `gap.html` "공공시설"은 raw `faci_gb_nm='공공'`만 집계(W3, DB 재빌드 불필요).

## Premises (전부 동의, P6는 콜드 리드 반박으로 수정)

1. "와"는 보고서 1쪽과 심사위원이 혼자 여는 URL의 첫 60초에서 일어난다. 여정이 끝까지 렌더되려면 데모 페르소나에 체력 측정값까지 프리필돼야 한다. **사실**: 체력 레인 진입 경로 자체는 있다(`followUpChips` "체력 처방 시작" 칩 → PAR-Q → 폼). 없는 것은 측정값 프리필과 자동 진행 — 심사위원이 값을 지어내 넣어야 C를 본다.
2. 회색지대는 간판이 아니라 여정에 건다. 랜딩 카피 중립 유지(1심 제약), 데모 1번 페르소나와 보고서 첫 사례 = P2(27세 낀 계층)·P5(32세 지체장애 비저소득). 회색지대는 실용성(시장 규모) 축에 유리.
3. 발전가능성 20점은 문장 + 클릭할 물건으로 딴다. 공급공백 엔진 → "가맹 유치 우선순위 = B2G 자산" 가격표(가정 표기) + 도달 역설(웹 0.9%)에는 B2B2C 채널 실명 후보 + 접촉 시도 1건(결과는 사실대로).
4. HTTPS는 자격요건 수준. "주의 요함" 경고 + geolocation 실패는 정직·신뢰를 파는 제품의 첫인상을 부순다.
5. 헤드라인은 2기둥("정보가 안 닿고 71.5% / 닿아도 갈 곳이 없고 44.3%"). 3번 절 "가려 해도 5순위"는 인터뷰 조건부였으므로 규칙대로 제거. 5순위 카드는 P5 화면에 제도 사실로 유지.
6. **(수정)** 새 기능은 불필요하다. 단 **심사위원이 혼자 밟는 경로 위의 코드는 P0**: 자동재생 · 체력 프리필 · **✗ 판정 자부담 수학**(비적격인데 지원금 차감돼 "무료"/"내 부담 15,000" — 신규 발견) · ⚠#8(수강료·지원·자부담 3셀 전부 null→"무료"/"−0원") · ⚠#9(영상 썸네일 http → HTTPS 후 mixed-content 깨진 이미지 3개) · ⚠#10(✗ 사용자에게 가맹시설 1순위 노출) · ⚠#14(챗 reply/slot 불일치 D-08·D-10) · 대체경로 중복 · C-27 종목 별칭(체력단련장→헬스, 없으면 공공 대안 매칭 0). ⚠#1(좌표만 입력)은 챗 UI가 좌표만 보내는 경로가 없어 심사 경로 밖 — API 위생으로 강등, W1 여유 시. 그 외는 문서·구성.

## Cross-Model Perspective (Claude 서브에이전트 콜드 리드, 요지)

- 가장 멋있는 버전: "설명 없이 스스로 재생되는 서비스" — 자동재생 + 뒷면 공급공백 표. 양면 제품이 독창성·발전가능성 두 축을 동시에 친다. → **채택(접근 B의 척추)**.
- 흥분 지점: "✗ 다음에 오는 문장". "지금 바로 되는 것"이 가장 공들인 화면이어야 하고, 체인을 한 스크롤로 압축해야 한다. 보고서 첫 문장은 "27세, 소득 '그 외', 성북구. 이용권 ✗ — 그 다음 문장이 스포내비다". → **채택**.
- P6 반박: ⚠#1·#8은 문서로 못 덮는 거짓 출력, 페르소나는 값이 없어 C에 못 감, 발전가능성 3~4점은 "클릭할 물건 공백". 증명: 모의심사 a/b 재실행, 낯선 사람 3명 60초 관찰. → **P6 수정으로 수용**.
- 하지 말 것: 챗 NLU 고도화, 새 기능·새 데이터소스. → **채택** (단 뒷면은 "정적 표 1장" 예외로 범위 개정 선언 — Constraints 참조).
- 내 유보: 뒷면은 3심 판사3이 경고한 지뢰. 제목·정렬을 "가맹 유치 우선순위"(공단이 다음에 할 일)로 두고 "0곳 순위표" 프레임 금지. 코드 전환기 잔재는 `region.count_scope` 영역그룹 합산으로만 노출(옛 서구뿐 아니라 제물포·영종 그룹 포함, 합산 후 228행).

## Approaches Considered

### A — 최소: 거짓 출력 0 + 보고서 재조립
HTTPS · ✗ 자부담 수학 · ⚠#8/#9/#10/#14 · C-27 별칭 · 대체경로 중복 제거 · P2/P5 체력 프리필 · 보고서 1쪽 P2 서사 · 헤드라인 2기둥 · 발전가능성 3줄 · 중개자 메일 1통 · 스샷 · 팀명. Effort S~M (human ~1.5주 / CC ~2일). Risk Low. 한계: 심사위원이 스스로 "체력 처방 시작" 칩을 눌러야 C를 본다, 발전가능성이 문장뿐.

### B — 이상: 양면 제품 (채택)
A 전부 + ①히어로 위계(덱 밖 전폭 블록) ②자동재생 딥링크 ③뒷면 `gap.html` ④낯선 사람 3명 60초 관찰 ⑤모의심사 a/b 재실행. Effort L (human ~4주 / CC ~8일 — W1 3일 + 자동재생 4일 + gap 1일). Risk Med.

### C — 측면: 이중 출품 (기각)
스포내비(B2C) + 공백 지도(B2G) 별도 출품. 기각: 2인 팀 5주에 보고서 2편은 현실 밖, 둘 다 70점 미만 위험, 3심 "조사를 동결하고 데모를 조립하라"와 충돌.

## Recommended Approach

**B, 단 A를 먼저 끝내고 시각 변경(히어로·인라인 강좌 행)은 9/5 이전, 시각 무영향 작업(자동재생·뒷면)은 9/5 이후, 9/17 코드·데이터 동결.** 3심 혐의 C(실행 역전)를 거꾸로 재발시키지 않기 위한 순서다.
