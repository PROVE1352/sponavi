# 되나요(Doenayo) 기획서 v1

> 2026 KSPO 공공데이터 활용 경진대회 · 서비스(앱·웹) 개발 부문 출품작.
> 작성 2026-07-20. 근거는 전부 실측·공식검증(출처 표기). 아이디어 법정 1심 PIVOT 판결의 제약을 제품 원칙으로 승격해 반영.

## 0. 한 문장

**"받을 수 있는 스포츠 복지를 몰라서 못 받는 사람"에게 — 자격을 판정해 주고, 안 되면 갈 수 있는 대안을 연결하고, 체력측정값으로 무엇을 하면 좋을지까지 알려주는 당사자용 내비게이터.**

- 간판 문구 후보 2안은 §8 검증 게이트(당사자 인터뷰) 후 확정: (A) 장애인 앵커 — "소득 무관인데 몰라서 못 받는 장애인 스포츠 복지" / (B) 스포츠 온램프 — "사각지대 계층을 국민체력100·이용권으로 태우는 입구"
- 두 안 모두 현 MVP가 이미 지원(레인이 같음). 간판은 카피 결정이지 구조 변경이 아님.

## 1. 문제 — 세 겹의 사각지대 (전부 실측)

### ① 오해 사각지대: "받을 수 있는데 안 되는 줄 안다"
- **장애인스포츠강좌이용권은 소득 기준이 없다** (만 5~69세 등록 장애인, 월 11만 원, 저소득은 '우선선정'일 뿐). 공식 검증 완료(문화포털 rcrtSn=197398 · mnuri.kr, 2026-07-20 확인).
- 그런데 이용권 하면 "저소득층 것"이라는 인식이 일반적 → **소득 때문에 자격이 없다고 오해해 신청 자체를 안 하는 집단**이 구조적으로 존재. "당신은 소득과 무관하게 대상입니다" 한 문장이 곧 서비스 가치.

### ② 자격자 미수령: "자격이 있어도 97%가 못 받는다"
- 서울 실측(2025, 문화빅데이터 활용정보): **차상위·한부모 커버리지 성동 1.5% · 중구 2.5% · 성북 3.8% · 노원 2.1%**. 기초수급도 20~29% 수준.
- 예산은 배정돼 있는데 전달이 안 되는 상태 — "부족"이 아니라 **"있는데 사장"**.

### ③ 공급 공백: "가라고 해도 갈 곳이 없는 지역"
- 전국 실데이터 DB(15.5만 시설) 실측: **인천 서구 — 이용권 가맹 383개, 장애인 가맹 0개.** 광주 북구 318:0, 광산구 307:0, 여수 126:0.
- 이 지역에선 어떤 안내 서비스도 무력 → 우리는 **추천하는 척하지 않고 공백을 그대로 신호**한다(§6 정직성 원칙). 이 신호 자체가 지자체·공단에 주는 2차 가치(발전가능성 축).

## 2. 타겟 — 자격(O/X) × 장애(O/X) 4케이스

| 케이스 | 인물 예 | 서비스가 주는 것 |
|---|---|---|
| P1 비장애·자격O | 10세 기초수급 아동 | "대상입니다" + 신청법 + 근처 가맹강좌 + **자부담 계산**(월 10.5만 지원 대비) |
| P2 비장애·자격X (낀 계층) | 27세 차상위 바로 위 | 대체경로 → 공공시설 무료/저가 프로그램 + 체력처방 |
| P3 장애·자격O | 14세 지체장애 | **"소득 무관 대상입니다"**(오해 해소) + 장애인 가맹시설(접근성) |
| P4 장애·자격X | 72세 청각장애(연령 초과) | 장애 특화 대안 + (공백 지역이면) 공급공백 신호 |

- 낀 계층은 4케이스 중 하나로 다루고 간판에 걸지 않는다(1심 검사 혐의2: near-poor 수요 미문서화 — §8에서 검증).

## 3. 솔루션 — 3레인 구조

```
[레인1 · 자격 판정]  결정론 규칙(rules.json, 공식 출처 인코딩) → "예상 자격 ✓/✗ + 사유 + 신청법"
[레인2 · 자원 연결]  전국 SQLite(15.5만 시설·9만 강좌) 쿼리 → 근처 가맹/공공/장애인 시설·강좌·자부담
[레인3 · 체력 처방]  국민체력100 전 측정항목 입력 → AI(LLM)가 약점·우선순위·운동 처방
                     → 처방 운동을 레인2의 실제 강좌와 다시 결정론 매칭
```

- **레인 분리 원칙**: 틀리면 안 되는 것(자격·위치·가격)은 결정론, 섬세함이 값인 것(처방 조언)만 AI. *자격 오판은 무응답보다 나쁘다*(1심 판사2).
- 항상 켜지는 **정직 신호 레이어**: 공급공백 배너 + 시군구 커버리지 통계("이 구 차상위 수급률 3.8%") + 자격은 "예상"이며 최종 확인은 공식 신청처.

## 4. 차별화 — 왜 기존 것들이 못 하나 (선행 전수조사 근거)

| 기존 | 한계 (조사 확인) |
|---|---|
| 복지로 맞춤형급여안내 | 상황입력→매칭은 있으나 **자격 미달 시 대안 없음**. 스포츠 특화 아님 |
| svoucher/dvoucher 공식 | **확정 수급자 전용**(자격 판정·오해 해소 없음), 챗봇은 FAQ형 |
| 보조금24·토스 지원금 | 전분야 리스트업, 대안 경로·시설 연결·체력 축 없음(토스는 종료 정황) |
| 2024 대상(동영상 추천 챗봇) | **운동 추천**(건강 문제). 우리는 **복지 접근**(권리 문제) — 문제 축이 다름 |
| 2025 대상(청소년 재능발굴) | 재능 프레임. 우리는 접근·형평 프레임 |

**부재 패턴(조사 확정)**: "자격 판정 + 미달 시 대안 연결"을 함께 하는 국내 서비스 없음 · near-poor 조준 체육 서비스 없음 · 스포츠 복지 자격을 지식그래프/규칙으로 추론하는 시민용 서비스 없음(학술도 4요소 결합 부재).

## 5. 심사 기준 매핑 (배점표 원문 미확인 — 공고 확인 즉시 갱신)

| 추정 축 | 우리 대응 |
|---|---|
| 활용성 | 실데이터 28만 행(공모 요건인 KSPO 데이터 7종 실사용), 실좌표 지도, 자부담 계산 — "지금 쓸 수 있음" |
| 독창성 | 문제 축 전환(추천→접근/권리) + 오해 해소("소득 무관") + 공급공백 정직 신호 |
| 사회적 가치 | 취약·장애인 당사자 직접 + 실측 격차 수치 제시(3.8%·383:0) |
| 발전가능성 | 커버리지·공백 데이터가 그대로 지자체/공단용 인사이트(특별상 축), v2 운동 온톨로지 |
| AI 결합(주최 성향) | 레인3 LLM 처방(§7) — 단 "AI 추론"이 아니라 "AI 보조 + 전문가 큐레이션 규칙" 프레이밍 |

## 6. 정직성 원칙 (1심 판결 제약의 제품화 — 전 화면 공통)

1. 공급공백은 숨기지 않고 배너로 신호한다 (검사 혐의1 대응)
2. near-poor는 간판이 아니라 케이스다 (혐의2)
3. 대체경로는 "전문가 큐레이션 규칙"이며 화면에 그렇게 표기한다 (판사2)
4. 경로 시각화로 "왜 이 결과인가"를 3분 안에 체감시킨다 (혐의3)
5. 자격 수치는 공식 출처+확인일 각주, 미확인은 "공식 확인 필요" 배지 (날조 금지)

## 7. AI 체력 처방 (레인3 설계 요지 — 상세는 ARCHITECTURE §6)

- **입력**: 국민체력100 측정항목 전체(measurement_item 카탈로그 기반, 연령군별 해당 항목 동적 폼 — 신체구성·근력·근지구력·심폐·유연성·순발력·민첩·평형·협응)
- **출력**: 약점(등급·근거) → 우선순위 → 처방(운동·강도·주당빈도) → 주의 문구, JSON 스키마 강제
- **프로바이더**: 지금 claude CLI(sonnet, 실검증 완료 — 42초/건), 프로덕션 Gemini 교체 가능하게 인터페이스 추상화. LLM 죽으면 룰 기반 fitness_map 폴백(서비스 무중단)
- **경계**: AI는 처방 조언까지만. "어느 강좌 가라"는 처방 운동↔DB 강좌의 결정론 매칭

## 8. 검증 계획 (판결 반증실험 = 출시 게이트)

- **인터뷰(마감 7/27, 볼트 할일 발행됨)**: 이용권 미사용 자격자·낀계층 5~8명 — "왜 안 썼나"를 [몰라서/신청 어려워/시설 없어/의지] 로 분해. **'몰라서'가 유의미하면 간판 A/B 결정 + 원안 강화, '시설 없어'가 지배적이면 공급공백 신호·정책 축 승격.**
- 배점표 확보(7/24) → §5 갱신.
- 베타 지표(배포 후): 자격판정 완료율, "몰랐다" 반응률(판정 화면 1클릭 설문), 대안 클릭률.
