# 7/27 인터뷰 프로토콜 — 판정 규칙 사전 등록판

> 3심 명령 2 이행 문서. 목적: 검사 혐의 D("3번 기둥 무목격") 기각조건 충족 — **확증 수집이 아니라 반증 감도를 유지한 개방형 신문**.
> 이 문서의 판정 규칙은 인터뷰 시작 전에 확정된 것으로 간주하며, 결과를 본 후 수정하지 않는다(사전 등록의 의미).

## 대상·규모

- **미신청·미이용 장애인스포츠강좌이용권 자격자**(등록 장애인 본인, 미성년·의사소통 어려움 시 보호자) **5인 이상**. 섭외: 체대 네트워크.
- 이미 이용 중인 사람은 대상 아님(별도 1~2명 참고 인터뷰는 가능하나 판정 집계에서 제외).

## 진행 규칙 (유도 금지가 생명)

한 명당 10~15분. **Q1~Q4까지는 절대 보기를 제시하지 않는다** — "소득 때문에요? 시설이 없어서요?" 같은 예시 제시 금지. 침묵이 나오면 "천천히 생각나는 대로요"로만.

| 순서 | 질문 | 기록 포인트 |
|---|---|---|
| Q1 (라포·완전 개방) | "요즘 운동이나 체육활동은 어떻게 하고 계세요?" | 현재 활동·중단 이력 |
| Q2 (인지) | "혹시 '장애인스포츠강좌이용권'이라고 들어보신 적 있으세요?" | 인지 여부 O/X, 어디서 들었는지 |
| Q3-A (미인지자) | 제도 한 줄 설명("등록 장애인이면 월 11만원 강좌비 지원") 후 → "이런 게 있는 줄 왜 못 들어보셨을까요? 이런 정보는 보통 어디서 접하세요?" | **자유 응답 원문 그대로** |
| Q3-B (인지자) | "신청은 안 해보셨어요? 어떤 이유가 컸어요?" | **자유 응답 원문 그대로 — 여기가 사유 분해의 코어** |
| Q4 (후속 프로브 — 자유 응답이 끝난 뒤에만) | "또 다른 이유도 있었을까요?" (최대 2회 반복) | 추가 사유. 여전히 보기 제시 금지 |
| Q5 (직접 확인 — 반드시 마지막) | "신청해도 소득에 따라 선정 순위가 나뉘어서, 일반 소득이면 5순위라 대기가 생길 수 있다는 건 알고 계셨어요? 그게 신청할 마음에 영향을 주나요?" | 사전 인지 여부 + 반응 원문 |

- Q5를 앞당기지 않는다 — 순위 정보를 먼저 주면 이후 응답이 오염된다.
- 인용은 가능한 한 **원문 그대로** 메모(녹취는 동의 시에만). 이름·연락처는 기록하지 않는다(연령대·장애유형·지역 수준만).

## 사유 코딩 (인터뷰 후, 응답당 복수 허용)

`[A 인지-미도달]` 제도 자체를 몰랐다 / `[B 인지-오해]` 알았지만 자격을 오해(소득 등) / `[C 공급]` 갈 시설·프로그램·거리 문제 / `[D 순위-단념]` 순위·대기·탈락 우려로 포기 / `[E 절차]` 신청 방법·서류 부담 / `[F 건강·의지·시간]` / `[G 기타]`

- D 판정 기준: **Q4까지의 자발 언급만 정식 D로 집계.** Q5 유도 후 "그래서 안 했다"는 반응은 `D*(유도후)`로 별도 표기 — 정식 집계에 불포함.

## 판정 규칙 (사전 등록 — 결과 확인 후 변경 금지)

1. **헤드라인 3번 절("가려 해도 5순위") 생사**: 정식 `[D]` 실인용 **≥1건 → 유지** / **0건 → 헤드라인을 2기둥으로 축소**("정보가 안 닿고, 닿아도 갈 곳이 없다") — 5순위 카드는 제품 기능으로는 유지하되 헤드라인에서 내림.
2. **강조점 조정(부차)**: A+B 합계 vs C 카운트 비교 — A+B 우세면 장벽1 서사 강화, C 우세면 장벽2(공백 엔진) 강조 유지. 동수면 현행 유지.
3. 인용 수집: 보고서·발표용으로 익명 인용 2~3개 확보(동의 받은 것만).

## 결과 처리

- 완료 즉시 결과를 볼트 사건 파일(E89 예정)에 원문 박제 → 판정 규칙 적용 → 헤드라인 확정 → PRD §0.5 갱신.
- 이 결과가 3심 검사 혐의 D의 기각조건이자 2심 보완명령 1의 최종 이행이다.
